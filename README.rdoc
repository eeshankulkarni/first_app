== Mini Mario (Standalone Web Version)

A browser-playable Mario-style mini game is available as static files, so it does not depend on Ruby/Rails runtime compatibility.

=== Where to play

* Open +public/mario/index.html+ directly in your browser, or
* Serve the +public+ directory and visit +/mario/index.html+.

Example with Python:

  cd public
  python3 -m http.server 8000

Then open:

  http://localhost:8000/mario/index.html

=== Controls

* Left/Right arrows (or A/D): move
* Space / Up (or W): jump
* R: restart
